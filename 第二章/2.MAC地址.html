MAC 地址

物理地址 · 网卡的全球唯一身份标识

Media Access Control Address

一、什么是 MAC 地址

MAC 地址（Media Access Control Address），又称物理地址（Physical Address）或硬件地址（Hardware Address），是烧录在网卡（NIC）ROM 中、由 IEEE 统一管理的全球唯一标识，工作在 数据链路层，用于在局域网内唯一标识每个接口/站点。

44-2A-60-1F-3B-8C
关键区分 —— MAC 地址 vs IP 地址：
IP 地址：逻辑地址，工作在网络层，可随网络位置改变，实现跨网络寻址；
MAC 地址：物理地址，工作在数据链路层，出厂固化、全球唯一，只在本局域网内寻址。

二、MAC 地址的格式与构成

  • 长度：48 位（6 字节），共 2⁴⁸ ≈ 2.8 × 10¹⁴ 个可用地址；
  • 表示：十六进制，每 8 位一组，常用连字符 44-2A-60-1F-3B-8C、冒号 44:2A:60:1F:3B:8C 或点分 442A.601F.3B8C（Cisco 格式）；
  • 构成：前 3 字节（24 位）为厂商代码 OUI，后 3 字节（24 位）为厂商分配的序列号。
48 bit 构成：44-2A-60 | 1F-3B-8C
└──── OUI 厂商代码（IEEE 分配）────┘ └──── 序列号（厂商自定）────┘

注意：网卡的 MAC 地址是硬件固定的，但可通过驱动程序修改（MAC 地址欺骗/克隆），这是合法的网络管理手段，但也可能被用于绕过访问控制。

三、MAC 地址的类型

判断依据：目的地址首字节的最低有效位（I/G 位），以及是否全 1：

类型 判定特征 作用范围 示例
单播（Unicast） I/G = 0（首字节为偶数） 唯一一个站点 44-2A-60-1F-3B-8C
组播（Multicast） I/G = 1（首字节为奇数） 一组站点 01-00-5E-00-00-01
广播（Broadcast） 全部 48 位为 1 本网段所有站点 FF-FF-FF-FF-FF-FF
记忆技巧：首位为奇数 → 组播，全 FF → 广播。广播地址是组播地址的一种特殊情况，二者都不属于任何单一设备。

网卡对收到的帧如何处理

  1. 目的 MAC = 本机单播地址 → 接收；
  2. 目的 MAC = 本机加入的组播地址 → 接收（组播过滤）；
  3. 目的 MAC = 广播地址 → 接收；
  4. 其余一律 丢弃。

四、MAC 地址表与交换机

交换机通过维护一张MAC 地址表（端口-地址映射表）实现帧的精确转发：

MAC 地址 所在端口 老化时间
44-2A-60-1F-3B-8C Fa0/1 300 s
00-1A-2B-3C-4D-5E Fa0/3 300 s
… … …

表项的建立靠自学习：收到帧时记录源地址与入端口；转发时查目的地址——命中则单播转发，未命中则泛洪，之后接收方回包即可让交换机"记住"它。

易错点：MAC 地址表是交换机的设备，不是路由表。路由器使用的是 IP 路由表（网络层），二者不要混淆。

五、MAC 地址的典型应用

ARP 协议
以太网帧寻址
交换机地址表
MAC 地址过滤/绑定
无状态地址自动配置（IPv6 SLAAC）
  • ARP通过 IP 地址解析出对应主机的 MAC 地址（见网络层章节）；
  • IPv6接口地址可由 MAC 地址经 EUI-64 算法自动生成（SLAAC），无需 DHCP；
  • 安全路由器/交换机可配置 MAC 过滤（允许/禁止特定设备入网）与端口安全绑定。

六、要点小结

  • 定义数据链路层物理地址，48 位 / 6 字节，十六进制表示，全球唯一。
  • 构成OUI（前 24 位，IEEE 分配）+ 厂商序列号（后 24 位）。
  • 类型单播（I/G=0）、组播（I/G=1）、广播（全 FF）。
  • 作用域仅限本局域网，跨网段传输时帧的 MAC 逐跳改写，IP 不变。
  • 配套ARP 解析 IP→MAC；交换机 MAC 表实现精准转发。
  • 考点MAC 地址与 IP 地址区别、I/G 位判定、广播地址 FF-FF-FF-FF-FF-FF。
